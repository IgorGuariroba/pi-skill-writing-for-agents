# pi-skill-writing-for-agents

**writing-for-agents** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Writing documents for agents. Use when creating or editing skills, or modifying AGENTS.md or CLAUDE.md.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-writing-for-agents
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-writing-for-agents.git ~/.pi/agent/skills/writing-for-agents

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-writing-for-agents.git ~/.agents/skills/writing-for-agents
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:writing-for-agents
```

Or let Pi automatically route to it based on conversation context and need.
